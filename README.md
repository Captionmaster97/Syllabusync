# SyllabusSync — Your semester, in sync

A student syllabus and study progress dashboard. Organise subjects into units and topics, track completion, plan weekly study goals, and compare progress with a demo study circle.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy
Upload the contents of this folder to GitHub and import the repository into Vercel. Framework preset: Next.js. No environment variables required.

## Prototype scope
This is a frontend prototype. Sample subjects and topic data are provided; progress, tasks and preferences are stored in browser localStorage. File parsing, real student accounts, shared study circles and notifications need a backend.
